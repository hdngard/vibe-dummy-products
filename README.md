## Приложение для работы с товарами (React + DummyJSON)

Это SPA на React + TypeScript для авторизации через DummyJSON Auth и работы со списком товаров из DummyJSON Products.
Приложение включает авторизацию, защищённый маршрут `/products`, таблицу товаров с сортировкой и поиском, а также добавление товаров на клиенте.

---

## Технологии

- **React 18+ / TypeScript / Vite**
- **React Router** — маршрутизация (`/login`, `/products`)
- **@tanstack/react-query** — работа с данными DummyJSON
- **Zustand** — локальное прикладное состояние (по необходимости)
- **Tailwind CSS** — оформление интерфейса

---

## Требования

- Node.js **>= 18**
- npm (или совместимый пакетный менеджер)
- Доступ в интернет для работы с API DummyJSON

---

## Установка и запуск

Все команды выполняются в корне проекта.

### 1. Установка зависимостей

```bash
npm install
```

### 2. Запуск в режиме разработки

```bash
npm run dev
```

После запуска откройте в браузере адрес `http://localhost:5173` (точный порт Vite будет показан в консоли).

### 3. Сборка в production

```bash
npm run build
```

Команда выполняет проверку типов (`tsc -b`) и собирает production‑бандл Vite в каталог `dist/`.

### 4. Предпросмотр production‑сборки

```bash
npm run preview
```

Откройте указанный в консоли адрес (обычно `http://localhost:4173`), чтобы посмотреть приложение в режиме, близком к production.

### 5. Линтинг

```bash
npm run lint
```

## Ручное тестирование ключевых сценариев

Сборка проекта успешно проходит командой `npm run build`, что подтверждает корректность типов и базовой конфигурации.
Ниже приведён чек‑лист для ручного тестирования в браузере.

### 1. Авторизация

- **Успешный вход**
  - Открыть `/login`.
  - Ввести валидные логин и пароль DummyJSON (например, `kminchelle` / `0lelplR`).
  - Нажать «Войти».
  - Ожидаемо: происходит переход на `/products`, ошибки не отображаются.

- **Пустые поля**
  - Оставить логин и/или пароль пустыми.
  - Нажать «Войти».
  - Ожидаемо: под пустыми полями появляются сообщения об ошибке, запрос к API не отправляется.

- **Неверные данные**
  - Ввести заведомо неверные логин/пароль.
  - Нажать «Войти».
  - Ожидаемо: отображается сообщение об ошибке авторизации.

### 2. Управление сессией и защищённый маршрут

- **Доступ без токена**
  - Перейти на `/products`, не авторизуясь.
  - Ожидаемо: происходит редирект на `/login`.

- **Сохранение сессии без чекбокса**
  - Войти с выключенным «Запомнить данные».
  - Обновить страницу на `/products`.
  - Ожидаемо: пользователь остаётся авторизованным в текущей вкладке, но после закрытия браузера и открытия новой вкладки требуется повторный вход.

- **Сохранение сессии с чекбоксом**
  - Войти с включённым «Запомнить данные».
  - Закрыть и снова открыть браузер, перейти на `/products`.
  - Ожидаемо: сессия восстанавливается, доступ к `/products` остаётся без повторного входа.

### 3. Работа со списком товаров

- **Загрузка и состояния**
  - После успешного входа убедиться, что:
    - При первой загрузке отображается индикатор загрузки.
    - При ошибке сети/серверной ошибке отображается сообщение об ошибке.

- **Сортировка**
  - Кликать по заголовкам столбцов цены и рейтинга.
  - Ожидаемо: порядок строк меняется, направление сортировки переключается (asc/desc) и корректно отражается в таблице.
  - Добавить новый товар и убедиться, что он учитывается текущей сортировкой.

- **Рейтинг**
  - Найти товары с рейтингом `< 3`.
  - Ожидаемо: значение рейтинга отображается красным цветом.

### 4. Поиск товаров

- Ввести часть названия, бренда или категории в поле «Поиск товаров».
- Ожидаемо:
  - Через ~300–500 мс список обновляется по результатам поиска (через DummyJSON `/products/search` и локальный поиск по добавленным товарам).
  - При очистке поля поиска список возвращается к полному набору товаров.
  - При отсутствии результатов отображается пустая таблица или соответствующее сообщение (в зависимости от реализации).

### 5. Добавление товара

- Нажать кнопку «Добавить» над таблицей.
- В модальном окне заполнить:
  - Наименование (обязательно, не пустое).
  - Цену (обязательно, число > 0).
  - Вендор (обязательно).
  - Артикул (по необходимости).
- Нажать «Сохранить».
- Ожидаемо:
  - При некорректных данных отображаются сообщения валидации.
  - При корректных данных модалка закрывается, появляется toast‑уведомление «Товар успешно добавлен».
  - Новый товар появляется в таблице и участвует в сортировке и поиске.
